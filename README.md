<h1 align="center">MedMinder</h1>

<p align="center">
  A simple, elderly-friendly medicine reminder for Android.<br>
  Works completely offline: nothing ever leaves the phone.
</p>

---

## Features

- **Reminders around your meals.** Set breakfast, lunch and dinner times once.
  Each medicine is taken *before food* (reminder 20 min before the meal) or
  *after food* (40 min after).
- **One reminder per session.** Everything due at the same time comes in a
  single notification that lists each medicine and how many to take. Medicines
  already taken are left out, so nothing is taken twice.
- **Act straight from the notification.**
  - **Taken ✓** marks the whole session as taken.
  - **Snooze** waits for your default time (10 min, changeable).
  - Quick choices: **5 min · 10 min · 15 min · 1 hour**.
- **Tap a reminder** to open a page listing what to take, each with a big
  **Taken** button.
- **Course dates.** Pick a start date and either an end date or "no end date"
  from a calendar. Quick picks: 5, 7, 10, 14 or 30 days.
- **Today at a glance.** The home screen groups today's medicines by session
  (Morning · Before breakfast, …).
  - Earlier sessions can still be ticked or corrected.
  - Later ones stay greyed out until about an hour before they're due.
- **Weekly report** (can be switched off). Every Monday at 9 AM: how many doses
  were taken last week, overall and per medicine.
- **Its own sound.** A soft, low-pitched bell chime played at alarm volume,
  easier to hear for people with age-related hearing loss.
- **First-run setup.** Asks for meal times and notification permission. If
  notifications are blocked, the home screen says so and offers a button to fix it.

### Designed for older users

- Large, high-contrast text in **Atkinson Hyperlegible**, a typeface designed
  for readers with low vision.
- Big touch targets (60–64 dp).
- Plain language and confirmations that stay on screen until dismissed.
- Follows the phone's own font-size setting.

## Privacy

- Medicines, meal times and the taken history are stored only on the phone
  (SQLite and shared preferences).
- The release app **does not request internet access**, so Android itself
  prevents it from sending anything anywhere.

## Install

Download the APK from the
[Releases](https://github.com/vijethmd/MedMinder/releases) page (if one is
published), or build it yourself.

Android 7.0 or newer. On Samsung and some other phones, set
**Settings → Apps → MedMinder → Battery → Unrestricted** so reminders are never delayed.

## Build

Requires Flutter 3.38+, JDK 17 and the Android SDK.

```bash
flutter pub get
flutter build apk --release              # one APK for all phones
flutter build apk --release --split-per-abi   # smaller APKs per CPU type
```

If your default Java is newer than 21, point Gradle at JDK 17,
e.g. `JAVA_HOME=/path/to/jdk-17 flutter build apk --release`.

Release builds are currently signed with the debug key, which is fine for
sideloading. For the Play Store, add your own signing key and change the
application ID (`com.example.med_minder`).

## How reminders work (for developers)

| Piece | Where |
|---|---|
| Sessions: 3 meals × before/after food = 6 reminder times | `lib/data.dart` (`Session`) |
| Scheduling, Taken/Snooze buttons, weekly report | `lib/reminders.dart` |
| Taken history (`dose_log`) and reports (`weekly_reports`) | `lib/data.dart` |
| Screens | `lib/screens/` |
| Theme and shared widgets | `lib/theme.dart`, `lib/widgets.dart` |

- Each session is a daily repeating notification (`flutter_local_notifications`).
- A background job (`android_alarm_manager_plus`) runs at **00:05** every day.
  It refreshes the lists as courses start or end, and prepares the weekly report.
- Android's daily repeat always fires at the *next* matching clock time and
  ignores the start date. So a reminder whose first day is later (a course
  starting next week, or a session already taken today) is scheduled once, and
  the 00:05 job turns it into a daily reminder on that day.
- `android/app/proguard-rules.pro` is required for release builds. Without it,
  the notification plugin can't read its saved reminders after a reboot.

The logo and chime are generated by scripts, so they can be tweaked and rebuilt:

```bash
python3 tool/make_logo.py . /tmp        # launcher PNGs + assets/images/logo.png
python3 tool/make_chime.py android/app/src/main/res/raw/medminder_chime.wav
```
